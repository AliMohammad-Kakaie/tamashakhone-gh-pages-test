# تماشاخونه — داشبورد عمومی نمایشی GH10.1

نسخه آزمایشی عمومی — بدون اطلاعات واقعی.

رابط کتابخانه، شناسنامه، فیلترهای ترکیبی، رتبه‌بندی، نمودار، مجموعه‌ها و سریال‌ها از کد رابط قبلی استفاده مجدد می‌کند. این نسخه کاملاً ایستا است و به API خصوصی یا ورود OpenAI وابسته نیست.

۲۸ اثر نمونه: عنوان‌ها، شناسه‌ها و پوسترهای قابل دریافت اطلاعات عمومی سینمایی هستند. تمام رویدادها، امتیازها، نظرها و پیشرفت‌ها ساختگی‌اند. نام دو ستون شخصی صرفاً برای آزمایش طراحی است و سابقه واقعی اشخاص را نشان نمی‌دهد. ستون IMDb هم **ساختگی** است؛ امتیاز واقعی این سرویس در این نسخه وجود ندارد. مقدار null با صفر متفاوت است.

## اجرا و آزمون
همه فایل‌های این پوشه در ریشه مخزن هستند. GitHub Pages از main و / (root) منتشر می‌کند. نصب، بسته‌سازی، سرور اختصاصی یا کتابخانه خارجی لازم نیست. فایل‌ها و importها نسبی‌اند. مسیر اصلی با پارامتر utm_source نیز کار می‌کند.

آزمون منطق با Node.js: `node --test tests.mjs`.

داده فقط از فایل عمومی `demo-bank.json` همین مخزن دریافت می‌شود؛ این فایل محل قرار دادن داده واقعی نیست. در خطا، پیام یا نسخه قبلی نمایشی با اعلام کهنگی نشان داده می‌شود؛ منبع واقعی دیگری وجود ندارد. تازه‌سازی یعنی بارگذاری دوباره همین فایل، نه همگام‌سازی بانک اصلی.

پوسترها در صورت دسترسی از image.tmdb.org بارگذاری می‌شوند؛ نبود یا شکست تصویر، جایگزین داخلی عنوان‌دار دارد. فونت، CSS، JavaScript و داده نمایشی همگی محلی‌اند. TMDB attribution در پایین صفحه باقی است. کشف خودکار پوستر و دریافت امتیاز زنده فعال نیست.

## محدودیت‌ها
هیچ ورود، پنل مدیریتی، مسیر ویرایش یا حذف بانک، Google Sheets، کلید API، اعتبارنامه یا سابقه شخصی واقعی در این بسته وجود ندارد. حفاظت آرشیو واقعی نیازمند منبع احرازهویت‌شده جداگانه است و در این نسخه پیاده‌سازی نشده است.
