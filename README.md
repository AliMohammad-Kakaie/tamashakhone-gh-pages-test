# تماشاخونه — رابط GH12.1

این کد ادامهٔ رابط GH10.1 است: گالری، جست‌وجو، فیلترها، شناسنامه، نمودار، رتبه‌بندی، فصل‌ها و مجموعه‌ها حفظ شده‌اند. فعال‌سازی نسخهٔ واقعی به تنظیم سرور و تأیید مالک وابسته است.

- این مخزن فقط رابط ایستا و اطلاعات عمومیِ سینماییِ قبلی را نگه می‌دارد؛ هیچ نسخه‌ای از بانک خانوادگی، رمز عبور یا اعتبارنامهٔ Google در فایل‌های این نسخه قرار ندارد.
- دادهٔ واقعی فقط از تابع سروریِ محافظت‌شده، پس از بررسی هویت و عضویت دریافت می‌شود. سایت راهی برای نوشتن در بانک ندارد.
- ورود با نام کاربری و رمز است. کتابخانهٔ رسمی Supabase نشست را در مرورگر نگه می‌دارد و تازه می‌کند؛ خروج دستی برقرار است.
- امتیاز ثبت‌نشده با صفر متفاوت است. امتیاز نمونه یا TMDB به نام IMDb نمایش داده نمی‌شود.
- فایل‌های دارای نام GH12 برای جلوگیری از اجرای کد قدیمی از کش استفاده می‌شوند. فایل‌ها و importها با مسیر پروژهٔ GitHub Pages سازگارند.
- فایل‌های نمایشی قدیمی GH10.1، اگر در مخزن باقی باشند، منبع رابط GH12 نیستند و دادهٔ واقعی را دریافت نمی‌کنند.
- بستهٔ Supabase در `supabase-vendor.mjs` محلی است؛ مجوز آن در `SUPABASE-LICENSE.txt` قرار دارد. فونت یا کتابخانهٔ رابط از CDN خارجی بارگیری نمی‌شود.

شاخه‌های بازگشت `gh10.1-baseline` و `mission-9-baseline` حفظ می‌شوند. انتشار Pages از `main` است؛ ذخیرهٔ کد در شاخهٔ آماده‌سازی به معنی انتشار یا فعال‌شدن نسخه نیست.
