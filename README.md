# تماشاخونه — آزمایش GitHub Pages

نسخه آزمایشی عمومی — بدون اطلاعات واقعی.

این نمونه فقط برای آزمایش دسترسی عمومی و رفتار رابط ایستا ساخته شده است.
هر چهار عنوان، سال و توضیح عمداً ساختگی‌اند. هیچ سابقه تماشا، امتیاز، نظر،
نام شخص، اطلاعات حساب، کلید یا اتصال بانک اطلاعاتی در این بسته وجود ندارد.

## اجرا و انتشار

این پوشه همان ریشه مخزن پیشنهادی `tamashakhone-gh-pages-test` است.
هیچ نصب، ساخت، کتابخانه بیرونی یا سرویس پولی لازم ندارد.

پس از بارگذاری همین فایل‌ها در یک مخزن عمومی مستقل با GitHub Free:

1. در Settings → Pages، گزینه Deploy from a branch را انتخاب کنید.
2. شاخه main و پوشه /(root) را انتخاب و ذخیره کنید.
3. فقط URL واقعی اعلام‌شده توسط GitHub Pages را برای آزمایش استفاده کنید.

همه مسیرهای CSS، JavaScript، ماژول و آیکون نسبی‌اند و با پیشوند نام پروژه
در GitHub Pages کار می‌کنند. پارامتر utm_source منطق مسیر را تغییر نمی‌دهد.
فایل .nojekyll برای انتشار مستقیم فایل‌های ایستا قرار داده شده است.

## حدود فنی

جست‌وجوی فارسی و انگلیسی، فیلتر نوع اثر و شمارنده فقط در حافظه همین صفحه کار
می‌کنند. داده‌ای ذخیره یا ارسال نمی‌شود. هیچ fetch، فرم، ورود یا API وجود ندارد.
سیاست محتوای صفحه اتصال شبکه از کد برنامه را با connect-src 'none' منع می‌کند.
فایل‌های ضروری همگی در همین مخزن هستند؛ هیچ فونت، پوستر یا ابزار آمارگیری خارجی
بارگیری نمی‌شود. خود میزبان ممکن است طبق سیاستش لاگ عملیاتی داشته باشد.

منطق نرمال‌سازی جست‌وجو از مدل خالص رابط قبلی و رنگ‌ها و شمارنده از نمونه عمومی
قبلی استفاده مجدد شده‌اند؛ دریافت API خصوصی، هویت Sites و Worker منتقل نشده‌اند.

این نمونه سامانه خصوصی یا مجوزی برای افزودن اطلاعات واقعی نیست. آن را برای
اطلاعات محرمانه یا عملیات سازمانی استفاده نکنید.
